# Programme MINESEC — Référentiel SmartLearn Unified

## Statut

⚠️ **Skill en squelette.** Contenu à remplir manuellement avec les programmes officiels
MINESEC. Tant qu'une matière/niveau n'est pas renseigné ici, tout agent qui invoque ce
skill doit produire `⚠️ donnée manquante — fournir : référence programme MINESEC pour
{matière} {niveau} {chapitre}` (cf. CLAUDE.md §4 anti-hallucination).

## Structure attendue

Pour chaque matière × niveau, lister :
- Texte de référence (ex : « Programme MINESEC 2014, Arrêté n° XXX »)
- Modules / chapitres ordonnés
- Objectifs Généraux (OG) et Objectifs Spécifiques (OS) par chapitre
- Prérequis et liens transversaux
- Volume horaire indicatif

## Sous-systèmes couverts

- **Francophone** : 6e, 5e, 4e, 3e, 2nde A/C/E/TI, 1ère A/C/D/E/TI, Terminale A/C/D/E/TI
- **Anglophone** : Form 1 → Form 5, Lower 6th, Upper 6th (Arts, Sciences, Commercial)

## Matières prioritaires (Phase 1 de remplissage)

1. Mathématiques — Terminale C (préparation Bac)
2. Mathématiques — 3e (préparation BEPC)
3. Physique-Chimie — Terminale C / D
4. Français — Toutes classes (épreuves communes)
5. Anglais — Toutes classes (sous-système francophone, LV1)
