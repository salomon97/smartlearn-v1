# Livrables — Mémoire PFNL / Diversité floristique, Lomié (AKOUMA AYISSI T. C.)

Documents produits en appui à la finalisation du mémoire. Toutes les valeurs
proviennent de la base de données finale (inventaire de 2 379 arbres + enquêtes
auprès de 50 ménages). Analyses sous Python 3.11 (pandas, NumPy, SciPy).

## Fichiers

| Fichier | Contenu |
|---|---|
| `1_Resultats_finalises.docx` | Les 4 résultats finalisés (TUT, diversité floristique, PFNL & contribution, contraintes/opportunités). 22 tableaux, 22 figures, interprétations + discussions. |
| `2_Analyses_statistiques.xlsx` | 8 feuilles d'analyses + 4 graphiques éditables + feuille « Logiciels et versions ». |
| `3_Conclusion_Recommandations_Perspectives.docx` | Conclusion par objectif, recommandations (ménages/MINFOF/ONG/chercheurs), perspectives. |
| `4_Resume_et_Abstract.docx` | Résumé (FR) + Abstract (EN) + mots-clés. |
| `5_Corrections_et_Vigilance.docx` | Corrections apportées + points de vigilance avant dépôt. |
| `figures/` | 20 figures haute résolution (300 dpi, PNG). |
